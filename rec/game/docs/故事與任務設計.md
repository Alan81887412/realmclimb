> 故事設計總監｜對應資料檔 `game/js/story.js`（全部對白都在那裡，這份只寫設計）。

## 一、世界觀與基調

**鐵環。** 最早這裡只有一根拴獸樁和樁上的鐵環。人們圍著它看人獸相搏，看臺、街道、城牆一圈一圈往外蓋，成了鐵環城。全盛時期這是角鬥士與馴獸師的城市：鬥獸養在北方的獸欄，往上一層的門開在獸欄後面，上層礦都的鐵與貨物從那裡運下來。

**斷鍊之夜（十二年前的冬夜）。** 第一百場冠軍戰，九十九戰全勝的黑鬃獅子「鐵鬃」對角鬥士葛倫。鐵鬃走出北門，鬥獸們跟著衝了出去。牠沒有逃向遠方，而是回到關了牠半輩子的獸欄，把牢房坐成王座。往上的路斷了，原野歸野獸所有，人退回城牆裡。對外的說法是「鍊子被掙斷了」；真相分散在隱藏任務裡（見第四節）。

**三隻菁英。**
- 霜背（草原最南邊）：生在草原、沒見過籠子的頭狼，背上一道白毛。夜裡的嚎聲從正南方傳到城牆。
- 老疤（森林西側最深處）：競技場開場戲的熊，打了九年。出手前先人立怒吼，是競技場教牠的「先給觀眾看」。斷鍊之夜後獨自進了森林，只想被放過。左前掌少一根趾（哈根砍的）。
- 影牙（峽谷東側岔路盡頭）：在場上從不先動的虎，等對手轉身才撲。如今守著通往獸欄的峽谷。

**這一層想讓玩家感受到的：**
1. 位置對調：從前人把野獸拴在環裡，現在是野獸把人圍在城牆這個環裡。
2. 野獸不是壞人：各有脾氣與規矩，看懂牠比砍贏牠重要（對應戰鬥教學：看預警、認習性）。
3. 一個人走不遠：獸欄的門要兩人同時轉絞盤（設定上是當年故意這樣做，免得一個人把獸欄打開），全城都在等一支攻略團。
4. 溫暖帶點幽默：NPC 各有口頭禪；沉重的往事留給願意打聽的人。

文案只說「第一層」「上面一層」，沒有寫死世界是塔還是別的形狀。`LORE.intro` 有五句開場白可在新角色進場時播放。

## 五、需要遊戲端支援的功能

**一定要有（沒有就接不起來）**
1. 多任務並行與任務日誌：依 `pre` 解鎖、`giver` 頭上標記、多個目標、顯示評級與建議等級。存檔的任務欄位要從單一進度改成多任務進度（建議舊進度直接作廢，從 m01 開始）。
2. 五種目標：kill、elite、collect（交任務時扣除）、talk、reach。reach 用 `PLACES` 的座標與半徑判定；elite 建議「持有戰利品也算完成」且不扣戰利品（h03 要用）。
3. 新增六位 NPC（world.js 的 npcSpots；哈根在野外）。對話介面建議三個選項：任務、閒聊（idle）、打聽（rumors）；talk 目標要播 `say`。
4. 指引：`{ zone }` 標出整個區域，`{ x, z, r }` 畫一個大圈（圓心故意不在目標上），`null` 不顯示。
5. orbChoice：多個代號時讓玩家選一顆，只有一個時直接給。

**有了才完整（沒有也能玩，會自動退化成較簡單的版本）**
6. 目標的附加條件 `cond`（規則寫在 `LORE.conds`）：charge 對木靶蓄力、dodged 先閃再殺、guarded 先擋再殺、nohit 不受傷、warned 被熊威嚇後退開、allocated 點數配完、fragile 易碎品、night 夜間。這些是現有五種目標表達不了的；若要做成正式的新種類，建議加「do（做一次某個操作）」與「observe（觀察到某種怪物行為）」。
7. 隱藏任務的 `unlock`：reach（走到地點並跳旁白）、item（持有物品）、night（夜間）。
8. reach 的 `say` 旁白、任務的 `keys`（在日誌顯示對應按鍵）。

**場景小物件（沒有也能判定，只是少了可看的東西）**
競技場正中央的拴獸樁、鐵環與鎖；北大道盡頭草叢裡的斷鍊；獵人營地的帳篷與營火；峽谷岔路口翻倒的貨車。
